相位：一条贯穿振动与波动的线索

简谐振动的多种描述如何对应？振动方程与波动方程中的“相位”究竟是不是一回事？

先给结论。振动方程中的相位 Φ(t) = ωt + φ 只有一个自变量 t，是“一个质点走到哪一步”的时间刻度；波动方程中的相位 Φ(x,t) = ωt − kx + φ 有两个自变量，是“波线上每一点、每一时刻走到哪一步”的时空刻度。波动的本质，就是振动相位以速度 u 在介质中向前传播。

问题一简谐振动的几种描述形式

课程中描述同一个简谐振动，主要用了三种形式：解析式（振动方程）、曲线（x–t 图）、旋转矢量（相量图，图解法）。若再往数学上走一步，还有复数（相量）表示。它们不是四种不同的振动，而是同一振动的四种“语言”。

1. 解析式：代数语言

取平衡位置为原点、沿振动方向为 x 轴，简谐振动的标准形式为

x = A cos(ωt + φ)

其中 A 为振幅，ω 为圆频率，φ 为初相，(ωt + φ) 为相位。速度与加速度为

v = −Aω sin(ωt + φ) = Aω cos(ωt + φ + π/2)
a = −Aω2 cos(ωt + φ) = Aω2 cos(ωt + φ + π)

可见 v 的相位比 x 超前 π/2，a 与 x 反相（相差 π）。三要素由初始条件定出：

A = √(x02 + v02/ω2)，   tanφ = −v0/(ωx0)

用反三角函数求 φ 时，必须结合 x0、v0 的符号确定象限，不能只取主值。

2. 曲线法：图像语言

以 t 为横轴、x 为纵轴画出的 x–t 曲线，是一条余弦曲线。曲线直接给出“全貌”：峰值就是 A，相邻两个同相点（如相邻波峰）的时间间隔就是周期 T，而 t = 0 处的位移 x0 与曲线斜率（即 v0）共同确定初相 φ。

3. 旋转矢量法：几何语言

画一个长度为 A 的矢量 A，让它在 x 轴上以角速度 ω 逆时针匀速旋转，则矢量端点任何时刻在 x 轴上的投影就是 x = A cos(ωt + φ)。矢量与 x 轴的夹角就是相位，t = 0 时的夹角就是初相。

4. 复数表示：拓展

x = Re[A ei(ωt+φ)] = Re[(A eiφ) eiωt]

括号中的 Aeiφ 称为相量。旋转矢量是这个复数在复平面上的几何形象；用相量做加减、求导，比反复使用三角恒等式方便得多，这正是交流电路分析的基本工具。

四种形式的对应关系

要素解析式x–t 曲线旋转矢量

它们之间的联系可以一句话概括：解析式是精确的“代数语言”，曲线是直观的“图像语言”，旋转矢量是把相位几何化的“几何语言”；三者描述的是同一个 x(t)，三要素一一对应。相位在解析式中是括号里的一个数，在曲线中是“走到了周期的哪里”，在旋转矢量中则是“转过了多少角度”。正因为相位可以看成一个角，相位差才可以同时读成时间差 Δt = Δφ/ω 和几何夹角，振动合成也才可以转化为矢量相加。

问题二振动方程与波动方程中的相位

1. 振动方程中的相位：一个质点的时间刻度

对 x = A cos(ωt + φ)，相位为

Φv(t) = ωt + φ

它只随 t 变化，单位是弧度。给定相位，就确定了质点此刻的“运动状态”（位移和速度方向）：相位为 0 时在正最大位移处，π/2 时在平衡位置向负方向运动，π 时在负最大位移处，3π/2 时在平衡位置向正方向运动。φ 是 t = 0 时刻的相位，由振子的初始条件决定。

同一个振子在不同时刻的相位差为

ΔΦ = ωΔt = 2π Δt/T

它只反映“时间先后”，不包含任何空间信息。

2. 波动方程中的相位：一条波线的时空刻度

沿 x 轴正方向传播的平面简谐波，波函数为

y = A cos[ω(t − x/u) + φ] = A cos(ωt − kx + φ)，  k = 2π/λ

其相位为

Φw(x,t) = ωt − kx + φ

它同时依赖 t 和 x。固定 x，得到该点的振动方程，其初相为 φ − kx；固定 t，得到该时刻的波形图；令相位不变，ωt − kx + φ = 常数，两边微分得

ω dt − k dx = 0  ⟹  dx/dt = ω/k = λ/T = u

这说明：波速就是等相位面的推进速度（相速度）。波传播的不是质点，而是“相位”这个状态标记。

波动中的相位差有两种来源：同一点先后两个时刻，ΔΦ = ωΔt；同一时刻沿传播方向相距 Δx 的两点，

ΔΦ = −kΔx = −2π Δx/λ

负号表示沿传播方向相位依次落后。若波沿 −x 方向传播，则 Φ = ωt + kx + φ，ΔΦ = +kΔx。把两者合起来，就是统一形式

ΔΦ = ωΔt ∓ kΔx  （沿 ±x 传播）

3. 两者的区别

比较项振动方程 x = Acos(ωt+φ)波动方程 y = Acos(ωt−kx+φ)
自变量只有时间 t时间和位置 x、t
描述对象一个质点波线上所有质点（整个波形）
相位表达式ωt+φωt−kx+φ
初相的含义质点 t = 0 时的相位，由初始条件定原点（波源）t = 0 时的相位；x 处质点的初相是 φ−kx
相位差的来源只来自时间差：Δφ = ωΔt时间差 + 空间波程差：Δφ = ωΔt − kΔx

典型用途求三要素、初相、相位差求波函数、波形、干涉与驻波

4. 两者的联系

  1. 波动方程是振动方程在空间上的延拓。固定 x，y = Acos(ωt − kx + φ) 就是该点的振动方程，只是初相变成 φ − kx。因此一个波函数里“装着”无数个振动方程；反过来，知道了波线上每一点的振动，也就知道了整个波。
  2. 波是相位的传播。等相位点满足 ωt − kx + φ = 常数，它以速度 u = ω/k 前进。介质质点只在平衡位置附近振动，并不随波迁移；真正“跑”的是相位、振动状态和能量。
  3. 数学形式统一。两者都是“圆频率 × 时间 ± 波数 × 位置 + 初相”的余弦函数，相位差都可写成 ΔΦ = ωΔt ∓ kΔx。振动取 Δx = 0，波动取 Δt = 0，就分别退化为各自熟悉的公式。
  4. 干涉与驻波是相位在空间中的叠加。两列波在空间某点叠加，合振幅由 Δφ = φ2 − φ1 − 2πΔr/λ 决定；驻波则是相位分布被两列反向波“冻结”，相邻波节之间同相、波节两侧反相；半波损失本质上就是反射时相位突变 π。
  5. 初相的来源不同，但地位相同。振动中的 φ 由振子的初始位移和速度决定；波动中的 φ 由波源（原点）的初相决定，再沿波线逐点减去 kx。两者都表示 t = 0 时刻的相位，都是通过初始条件或边界条件定出的积分常数。
  6. 能量图像互为对照。振动中动能与势能反相变化、总能量守恒；波动中任一质元的动能与势能同相变化、总机械能不守恒，能量随相位一起向前传播。这一“反相/同相”的差别，正是“振动不传播能量、波传播能量”的微观原因。

5. 常见易错点

  • 把波函数中的 φ 当成“x 处质点的初相”。实际上该点的初相是 φ − kx。
  • 沿 +x 传播时，相位随 x 增大而减小（落后），所以 Δφ = −2πΔx/λ，不要漏掉负号。
  • 把波形图的斜率当成质点速度。波形图斜率 ∂y/∂x 与质点速度 ∂y/∂t 满足 ∂y/∂x = −(1/u)∂y/∂t，二者不是一回事。
  • 用 tanφ = −v0/(ωx0) 求初相时忘记判象限，导致相差 π。
  • 把相位当成角度制。相位是弧度，Δφ = 2πΔx/λ 中的 2π 不能写成 360° 混用。
一句话记忆。振动相位是钟表上的指针，只有时间在走；波动相位是沿波线铺开的一把刻度尺，时间在走，刻度本身也在向前传。波，就是“相位在跑”。

答题版（可直接整理到作业）

（1）课程中用三种形式描述简谐振动：①解析式 x = Acos(ωt+φ)；②x–t 曲线；③旋转矢量法（图解法）。三者描述同一振动，三要素一一对应：振幅 A 对应曲线峰值和矢量长度；ω 对应 t 的系数、2π/T 和矢量旋转角速度；初相 φ 对应 t=0 的初始条件（x0、v0）和 t=0 时矢量与 x 轴的夹角；相位 ωt+φ 对应曲线上的位置和矢量转过的角度。旋转矢量把相位几何化为角度，因此相位差就是夹角，振动合成就是矢量相加；若用复数表示，则 x = Re[Aei(ωt+φ)]，相量 Aeiφ 与旋转矢量一一对应。

（2）振动方程 x = Acos(ωt+φ) 中的相位是 Φv = ωt+φ，只随时间变化，描述一个质点的运动状态，初相由初始条件决定，相位差 Δφ = ωΔt 只反映时间先后。波动方程 y = Acos(ωt−kx+φ) 中的相位是 Φw = ωt−kx+φ，随时间和位置共同变化，描述波线上所有质点的集体状态，其初相是原点（波源）的初相，x 处质点的初相为 φ−kx；相位差 Δφ = ωΔt−kΔx，既包含时间差也包含波程差。联系在于：固定 x，波动方程退化为该点的振动方程；波正是振动相位以速度 u = ω/k 在空间的传播，等相位面的推进速度就是波速。干涉、驻波和半波损失，本质上都是相位在空间分布与叠加的结果。
